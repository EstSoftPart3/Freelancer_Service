## 확인 항목 (4건)

- [v] **1. 메인 인기 프로젝트가 모집중만 나오는지** — `http://localhost:3000/`
  - 카드가 **4장**이고 전부 `채용중` 상태인지 (전체 30건 중 모집중이 4건뿐이다)
  - 부제가 "지금 모집 중인 공고 가운데 관심이 높은 프로젝트입니다"로 바뀌었는지
  - 조회순 / 스크랩순 / 지원순 전환 시 순서만 바뀌고 4장 유지되는지
  - ※ 5칸 그리드라 마지막 칸이 빕니다. **가짜로 채우지 않기로 한 결정에 따른 것**이고,
    모집중 공고가 5건 이상 되면 자동으로 채워집니다.

- [v] **2. 프로젝트 회사명 검색** — `http://localhost:3000/projects`
  - 검색 타입을 **회사명**으로 바꾸고 `신한` 검색 → 결과가 전부 `(주) 신한은행`인지
  - **목록 하단 페이지 번호가 결과 수와 맞는지** ← 이번에 고친 핵심(종전에는 총 건수가
    전체검색 기준이라 있지도 않은 뒷 페이지가 생겼다)
  - **지도** 탭으로 전환 → 좌측 "결과 10건"이 목록과 같은지, 마커가 검색 결과만 찍히는지
  - 검색 타입 **전체**로 `신한` 검색 → 회사명도 잡히는지 (종전에는 0건이었다)

- [v] **3. 베스트글 선정 기준 안내** — `http://localhost:3000/community`
  - "베스트글" 옆 ⓘ 클릭 → 아래 3줄이 추가돼 있는지
    - 기간은 **작성일** 기준(댓글·추천이 달린 날 기준이 아닙니다)
    - 자유게시판·Q&A 글만 집계하며, 공지사항은 제외됩니다
    - 삭제된 글은 집계에서 빠집니다
  - 맨 아래 "이 목록은 **월간 인기**(최근 30일 작성글) 기준입니다."
  - 우측 "추천글" 옆 ⓘ → 같은 내용 + "이 목록은 **주간 인기**(최근 7일 작성글) 기준입니다."
  - `/community/list`의 사이드바 위젯 ⓘ → **탭을 바꾸면 맨 아래 줄이 따라 바뀌는지**
    (지금 인기 → 최근 1일 / 주간 인기 → 최근 7일 / 월간 인기 → 최근 30일)
  - ※ 사용자 요청으로 **"지금/주간/월간 인기" 3줄 나열은 제거**했다. 보고 있는 목록의
    기준만 맨 아래 한 줄로 알려준다.

- [v] **4. 기업 공고 모집상태 필터 무회귀** — `http://localhost:3000/mypage/affiliation-projects`
  (기업 `estsoft`로 로그인 → 마이페이지 → 소속 프로젝트)
  - 상단 **전체 / 채용중 / 채용예정 / 채용종료** 탭을 눌러가며
    - 탭별 **건수**가 표시되고, 목록이 그 건수와 맞는지
    - **채용중 + 채용예정 + 채용종료 = 전체**가 되는지
  - ※ 이 탭의 SQL 조건을 Phase 3에서 공용 조각(`<sql id="recruitingCondition">`)으로
    바꿨기 때문에 확인 대상이다. API로는 0 + 0 + 5 = 5로 이미 확인했고,
    **화면이 안 깨졌는지만** 보시면 된다.

- [v] **5. 프로젝트 등록 날짜 검증** (추가 작업분) — `/mypage/project-post`
  기업으로 로그인 → 프로젝트 등록에서 **일부러 모순되게** 넣어본다.
  - 수행 기간을 짧게(예: 다음 주 3일), 모집 기간을 그보다 **길게**(예: 두 달) 설정 후 등록
    → **"모집 종료일이 프로젝트 종료일보다 늦습니다…"** 토스트로 막히는지
  - 반대로 **수행 중 추가 모집**(수행 8/1~12/31, 모집 7/1~9/30)은 **정상 등록**되는지
    ← 이건 막으면 안 되는 정상 케이스다

  **전체 프로젝트 보기** 버튼이 뜬다.
