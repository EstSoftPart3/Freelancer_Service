## 1. 지금 바로 해야 할 것 — DDL 실행 승인

Phase 2·3·4·5가 전부 이 DDL에 걸려 있다. 공용 원격 DB(`db.estsw.co.kr` / `freelancer_project`) 스키마 변경이라 야간에 임의로 실행하지 않고 멈춰뒀다.

```bash
!python "C:/dev/Freelancer_Service/docs/phase1-ddl.py" --dry-run   # 계획만 출력(이미 확인함)
!python "C:/dev/Freelancer_Service/docs/phase1-ddl.py"             # 실제 적용
!python "C:/dev/Freelancer_Service/docs/phase1-ddl.py" --rollback  # 되돌리기
```

스크립트가 하는 일:
1. `TBL_USER_M` / `TBL_BOARD_M` / `TBL_COMMON_CODE_C` 를 `C:/dev/db-backup/<시각>-phase1/` 에 파일 백업
2. DDL 적용 (전부 **멱등** — 이미 있으면 건너뛰므로 재실행 안전)
3. 검증 출력 (컬럼·인덱스·백필 결과·신규 코드 7건)

적용 내용:

| 대상 | 변경 | 되돌리기 |
|---|---|---|
| `TBL_USER_M` | `user_nickname VARCHAR(20) NULL` + `uk_user_nickname` UNIQUE, `user_id` 값으로 백필 | 컬럼 DROP |
| `TBL_BOARD_M` | `board_category_cd BIGINT NULL` + `idx_board_type_category` 복합 인덱스 | 컬럼·인덱스 DROP |
| `TBL_BOARD_M` | `board_is_secret_yn CHAR(1) NOT NULL DEFAULT 'N'` | 컬럼 DROP |
| `TBL_COMMON_CODE_C` | 3200 게시판_카테고리 / 3201 자유 · 3202 일반 · 3203 현장정보 · 3204 기능요청 / 1404 고객의소리 / 2607 고객의소리 답변 | 7행 DELETE |

### 🔸 계획에서 바꾼 점 — 닉네임을 NOT NULL로 만들지 않았다

원래 계획은 `백필 → NOT NULL + UNIQUE` 4단계였다. 그런데 **지금 NOT NULL을 걸면 현재 가입 코드가 즉시 깨진다** — `UserMapper.insertUser`가 아직 닉네임을 넣지 않는데 컬럼에 기본값이 없어서다. 공용 DB라 다른 팀원 로컬까지 같이 죽는다.

UNIQUE는 NULL 중복을 허용하므로 지금 걸어도 안전하다. 그래서 **NULL 허용 + UNIQUE**로 두고, NOT NULL 전환은 가입 코드가 닉네임을 채우는 **Phase 2 마지막 단계**로 미뤘다.

동의하는지만 확인해주면 된다. (사전 점검 결과 회원 56명 / `user_id` 중복 0건 / 최대 15자라 백필 자체는 안전하다)

## 2. 판단이 필요한 것 3가지 (PR #303)

### ① 길찾기 출발지 자동설정이 사라졌다

기존엔 사용자 위치를 `from`으로 넣어 출발지가 미리 채워졌다. 그런데 좌표를 쿼리로 실으면 "URL에 좌표 노출" 차단이 무의미해져서 **목적지만** 넘기도록 했다.

- **그대로 둔다** — 사용자가 카카오 지도에서 출발지를 직접 고른다 (현재 구현)
- **되살린다** — 좌표를 POST 본문으로 보내고 URL을 응답받는 방식. 우리 URL엔 안 남지만 구현이 늘고 팝업 차단 회피 처리가 필요하다

### ② `.svg` 를 업로드 화이트리스트에서 뺐다

SVG는 내부에 스크립트를 품을 수 있어 저장형 XSS 벡터다. 이미지지만 의도적으로 제외했다.
기존에 올라간 svg가 있거나 업무상 필요하면 알려주면 되돌린다.

허용한 확장자: `jpg jpeg png gif webp bmp pdf doc docx xls xlsx ppt pptx txt csv hwp hwpx zip`

### ③ `application.yml` 은 각자 반영해야 한다 (git-ignored)

첨부 한도를 올리는 아래 두 줄이 PR에 안 들어간다. **안 바꾸면 5MB 파일이 백엔드에서 413으로 잘려** FO 검증과 어긋난다.

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 5MB      # 기존 1MB
      max-request-size: 20MB  # 기존 1MB
```

내 로컬은 이미 반영했다. 팀 공지가 필요하다.
