## 이 게시판은 무엇을 위한 곳인가요

혼자 30분 헤맨 문제가, 남에게는 이미 지나온 길인 경우가 많습니다.
그 30분을 서로 아껴주자는 것이 이 커뮤니티의 전부입니다.

그래서 이곳에서 가장 가치 있는 글은 **잘 정리된 정답**이 아니라
**막혔던 상황이 그대로 담긴 질문**입니다. 검색해서 들어온 다음 사람이 읽는 것도 그쪽입니다.

게시판은 두 개입니다.

- **Q&A 게시판** — 막힌 것을 묻고 답합니다. 답변을 채택할 수 있습니다.
- **일반게시판** — 질문이 아닌 이야기. 자유 / 현장정보 / 정보 / 기능요청 중에서 고릅니다.

---

## 1. 질문하는 법

### 제목은 검색해서 찾을 수 있게

제목은 **나중에 같은 문제를 겪을 사람이 검색창에 칠 문장**으로 씁니다.
이 글들은 검색엔진에 그대로 노출됩니다.

- ❌ `질문있습니다`, `도와주세요ㅠㅠ`, `에러났어요`
- ⭕ `JWT 리프레시 토큰을 쿠키에 저장할 때 SameSite 설정 기준`
- ⭕ `MyBatis foreach 로 IN 절을 만들 때 빈 리스트면 SQL 오류가 납니다`

### 본문에는 세 가지가 있어야 합니다 (200자 이상)

1. **상황** — 무엇을 만들고 있었고, 어떤 환경인가 (버전·프레임워크까지)
2. **시도** — 무엇을 해봤고 어떻게 됐는가
3. **막힌 지점** — 정확히 어디서 멈췄는가. 에러 메시지는 잘라내지 말고 그대로

시도를 적지 않은 질문은 답변자가 처음부터 다시 추측해야 합니다.
**"무엇을 해봤는가"가 답변의 질을 결정합니다.**

### 붙이면 좋은 것

- 에러 메시지 전문 (스택트레이스 포함)
- 문제가 되는 코드 조각 — 파일 전체가 아니라 **재현되는 최소한**
- 스크린샷 (파일당 5MB, 합계 20MB)

---

## 2. 답변하는 법

### 300자 이상, 근거 하나 이상

- 공식 문서 링크, 실행해본 코드, 재현 절차 중 **최소 하나**를 넣습니다.
- 확신이 없으면 확신이 없다고 씁니다. `제 환경에서는 이렇게 해결됐는데 원인까지는 확인 못 했습니다` 는
  훌륭한 답변입니다. **틀린 단정보다 정직한 불확실이 낫습니다.**

### 이런 답변은 쓰지 않습니다

- `저도 궁금합니다`, `좋은 정보 감사합니다` → 이건 **댓글**로 답니다. 답변란은 해결을 위한 곳입니다.
- 검색 결과나 AI 답변을 확인 없이 그대로 붙여넣기
- 질문자를 탓하는 말투. `이건 기본인데요` 같은 문장은 다음 질문을 막습니다

### 답변에도 댓글을 달 수 있습니다

답변 내용이 궁금하면 그 답변에 바로 댓글로 되물으세요. 대댓글도 됩니다.

---

## 3. 답변을 받았다면 — 채택해주세요

질문자에게는 **채택할 책임**이 있습니다. 답을 받고 그냥 두는 것은
다음에 검색해서 들어온 사람에게 "여기 답이 있는지 없는지" 를 숨기는 일입니다.

- 도움이 된 답변 → **답변 채택하기**
- 스스로 해결했다면 → 어떻게 풀었는지 댓글로 남기고 **자체해결**
- 늦어도 **다음 날 오전까지** 처리합니다

> ⚠️ **채택은 되돌릴 수 없습니다.** 답변이 더 붙을 수 있으니 하루 정도 두었다가 고르세요.

## 4. 태그 규칙

### 기술 태그 — Q&A 는 최소 1개

Q&A 작성 화면의 **기술 태그**를 최소 1개 답니다 (`Spring Boot`, `React`, `MariaDB` …).
태그가 있어야 같은 주제 글이 한자리에 모이고, 검색이 됩니다.

### 일반 태그 — 소속 기수는 반드시

교육 과정으로 참여 중이라면 일반 태그에 **소속 기수 태그**를 답니다 (운영자가 별도 안내).

이 태그를 달면 아래 주소에서 우리 글만 모아 볼 수 있습니다.

```
/qna?tag=<기수태그>
```

## 5. 🔴 절대 올리면 안 되는 것

**이 게시판의 글은 검색엔진에 색인됩니다.** 지워도 캐시가 남을 수 있습니다.

- 본인·타인의 **실명, 연락처, 이메일, 주소, 주민번호**
- **회사 기밀, 고객사명, 계약 내용, 내부 시스템 주소**
- **접속 정보** — API 키, 토큰, 비밀번호, DB 접속 문자열
  (에러 로그를 붙일 때 여기에 섞여 들어가는 일이 가장 많습니다. **붙여넣기 전에 한 번 읽어보세요.**)
- 특정인을 겨냥한 비방, 광고·홍보성 도배

발견되면 사전 통보 없이 삭제합니다.
