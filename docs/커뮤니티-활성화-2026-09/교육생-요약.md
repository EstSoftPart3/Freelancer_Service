1. **가입** — `/sign-up` → 이메일 인증번호까지 입력 (**안 오면 스팸함**)

## 매일 (주 5일)

4. **~18:00 질문 1건** — `/qna/register`
   - 본문에 **상황 / 시도 / 막힌 지점** · 200자 이상
   - 태그: **기술태그 1개 + `<기수태그>`**

5. **~22:00 짝의 질문에 답변 1건** — 300자 이상 + 근거 1개
6. **~22:00 「오늘의 질문」에 답변 1건**
7. **~22:00 남의 답변에 추천 1회**
8. **다음날 10:00까지 — 어제 내 질문 채택** (또는 자체해결)
