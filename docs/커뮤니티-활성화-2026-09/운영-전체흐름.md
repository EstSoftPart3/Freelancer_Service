# 3단계 — 주간 점검 (매주 금요일 · 20분) · 나 혼자

교육생 글만 세려면 **봇 제외 조건**이 필요하다 — `user_id LIKE 'bot!_%' ESCAPE '!'`.

```sql
-- ① 사람이 쓴 글 (일자별) — 몰아쓰기 확인도 겸한다
SELECT DATE(b.board_created_at_dtm) d, COUNT(*) FROM TBL_BOARD_M b
  JOIN TBL_USER_M u ON u.user_sq=b.user_sq
 WHERE b.board_is_deleted_yn='N' AND u.user_id NOT LIKE 'bot!_%' ESCAPE '!'
 GROUP BY d ORDER BY d;

-- ② 무답변 질문 (0이어야 정상 = 로테이션이 지켜졌다)
SELECT b.board_sq, b.board_ttl FROM TBL_BOARD_M b
  JOIN TBL_USER_M u ON u.user_sq=b.user_sq
 WHERE b.board_type_cd=1402 AND b.board_is_deleted_yn='N'
   AND u.user_id NOT LIKE 'bot!_%' ESCAPE '!'
   AND NOT EXISTS (SELECT 1 FROM TBL_BOARD_ANSWER_S a
                    WHERE a.board_sq=b.board_sq AND a.answer_is_deleted_yn='N');

-- ③ 채택률 (1501 진행중 / 1502 채택완료 / 1503 자체해결)
SELECT board_adopt_status_cd, COUNT(*) FROM TBL_BOARD_M b
  JOIN TBL_USER_M u ON u.user_sq=b.user_sq
 WHERE b.board_type_cd=1402 AND b.board_is_deleted_yn='N'
   AND u.user_id NOT LIKE 'bot!_%' ESCAPE '!' GROUP BY 1;
```

## 알아둘 제약

| 사실 | 그래서 |
|---|---|
| 포인트·뱃지·활동점수 시스템이 **없다** | 동기 부여를 시스템이 대신 못 한다 → 과제·평가와 채택률로 대체 |
| rate limit·금칙어 검사가 **없다** | 몰아쓰기·저품질을 **주간 점검으로만** 잡을 수 있다 |
| 알림에 폴링·SSE가 **없다** | 사이트를 다시 열기 전엔 안 갱신된다. 대신 **이메일이 나가므로** 리텐션은 메일이 담당 |
| 추천(좋아요)에는 알림이 **없다** | 추천은 인기글 score(×3)용이지 상대에게 알림이 가지 않는다 |
| 봇 시드글이 09-28 까지 미래 날짜 | 최신순 상단이 3주차 후반까지 봇 글이다 → **기수 태그 링크가 유일한 모아보기 수단** |
| 되돌리고 싶다면 | `shift-seed-dates.py --from 2026-07-01 --to 2026-09-03 --apply` (봇 글만 대상, 프로그램 중에도 안전) |
