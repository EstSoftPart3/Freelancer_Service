## 1. 프로젝트 공고 (v2)

운영 현황: 지원 229건(모두 개인 지원), 기업이 이력서를 열람한 기록 0건(수정 전).
흐름은 인터뷰 확정(805)에서 끝난다. 최종 합격(803)을 처리하는 UI는 없고, 이번 흐름도에서는 여기까지만 다룬다. 기업이 소속원을 대신 지원시키는 경로는 §3에 있다.

```
 비로그인                  │ 기업                                 │ 개인
───────────────────────────┼──────────────────────────────────────┼──────────────────────────────────
 /projects 목록·상세 열람  │ [공고 등록하기] 클릭                 │
 (둘 다 공개)              │  ├ 기업 인증 전(2501) → 인증 안내창  │
 스크랩·지원 누르면        │  │   → 인증 페이지로 이동            │
  → "로그인 필요" 토스트   │  └ 인증 완료 → ① 공고 등록 폼        │
 /mypage 접근하면          │      └ 알림: 이 기업을 즐겨찾기한 ──▶│ ② /projects 검색·필터
  → 로그인 후 원래 화면    │        사용자 (메일은 안 보냄)       │   └ 공고 상세
───────────────────────────┤                                      │      ├ 스크랩 → 스크랩 목록·캘린더
                           │ 공고 목록 (상태는 날짜로 자동 계산)  │      └ 지원하기
                           │  채용예정 → 채용중 → 지원마감        │          └ 이력서 선택(필수)
                           │  (종료일이 지나면 자동으로 마감,     │             (없으면 이력서 등록으로)
                           │   조기 마감 기능은 없음)             │          🔧 채용예정·마감·삭제 공고는
                           │  수정·삭제 가능                      │             서버도 거절
                           │ ④ 지원현황 모달 ◀──알림+메일─────────│ ③ 801 지원중
                           │  ├ 이력서 열람 🔧 가능               │   └ [지원취소] → 806 ──▶ 기업에 알림
                           │  │  (열면 지원자 화면에 열람일)      │      🔧 지원중일 때만(서버도)
                           │  ├ [불합격] → 802 ──알림+메일───────▶│   불합격 확인
                           │  └ [인터뷰 요청] → 804 ──알림+메일──▶│ ⑤ 인터뷰 시간 직접 선택
                           │ ⑥ 캘린더에 면접 일정 ◀──알림+메일────│   └ 805 인터뷰확정 = 흐름 끝
```

- 🔧 지원 상태 변경·인터뷰 시간 선택 API는 당사자만 부를 수 있다. 합격·불합격·인터뷰 요청은 공고를 올린 회사, 지원취소·인터뷰 선택은 지원자 본인(대리지원이면 그 회사).
- 🔧 알림: 벨을 열 때마다 새로 불러온다. 새 지원자·지원취소 알림을 누르면 지원현황 모달이 바로 열린다. 관심기업 새 공고 알림은 공고 상세로 간다.

## 2. 이력서 (v2)

열람 권한: 예전엔 공고를 올린 기업 계정이 `TBL_COMPANY_MEMBER_R`에 없고 검사 기준도 지원자의 소속 기업이라, 기업이 지원자 이력서를 열 방법이 없었다(운영 열람 0건).
🔧 지금은 기업 계정의 회사(`TBL_COMPANY_S`)로도 판별하고, 근거는 ① 이 회사 공고에 지원 ② 이 회사에 소속 신청 ③ 이 회사 소속원이다.
열람 정책: 지원이나 소속 신청을 한 번이라도 받은 회사는 그 사람의 현재 이력서를 기한 없이 열 수 있다.

```
 비로그인             │ 개인                                        │ 기업
──────────────────────┼─────────────────────────────────────────────┼─────────────────────────────────
 /mypage/resume 접근  │ ① 이력서 작성 (/mypage/resume/new)          │ 이력서 작성 불가
  → 로그인 후 복귀    │   ├ 가입 정보 자동 채움 (이후 수정 가능)    │  (/mypage/resume → /mypage 이동)
                      │   ├ 필수: 제목·이름·생년월일·전화·          │ 인재 검색 기능 없음
                      │   │        이메일·주소                      │
                      │   ├ 선택: 사진·학력·경력·교육·자격증·       │
                      │   │        프로젝트·기술·첨부·자기소개      │
                      │   │  🔧 학력 검색 안 되면 [직접 입력]       │
                      │   └ 대표로 지정 가능                        │
                      │ ② 이력서 목록                               │
                      │   ├ 대표 이력서 설정 (1건만 유지)           │
                      │   ├ 수정 / 복사(파일 포함·제외) / 삭제      │
                      │   │  🔧 대표 삭제 → 최신 이력서가 대표      │
                      │   │  🔧 진행 중 지원·소속 신청에 쓰인       │
                      │   │     이력서는 삭제 불가                  │
                      │   └ 개수 제한 없음, 임시저장·공개설정 없음  │
                      │ ③ 이력서가 쓰이는 곳                        │
                      │   ├ 프로젝트 지원: 이력서 선택 ────────────▶│ 지원현황에서 이력서 열람 🔧
                      │   │   (대표 이력서가 미리 선택됨)           │
                      │   ├ 소속 신청: 이력서 선택 필수 ───────────▶│ 소속 신청자 관리에서 열람 🔧
                      │   │   🔧 본인 이력서만                      │
                      │   └ 기업 대리지원: 소속원의 대표 이력서 ◀───│ 🔧 이력서 보기·변경
                      │ ④ 열람 확인: 지원 내역의 열람일             │  (열람 알림은 따로 없음)
                      │   🔧 기업이 열 때만 기록(본인 제외)         │
──────────────────────┴─────────────────────────────────────────────┴─────────────────────────────────
 지원 기록은 이력서 복사본이 아니라 이력서 번호만 저장한다.
  → 지원한 뒤 이력서를 수정하면 기업 화면에도 바로 반영된다.
  → 🔧 진행 중(801·804·805, 소속 501)이면 삭제를 막는다. 끝난 지원만 남은 이력서는 삭제되고,
    기업이 열면 "이력서를 찾을 수 없습니다." 토스트가 뜬다.
```

## 3. 파트너(소속) (v1)

운영 현황: 소속 신청 0건, 소속원 0건(아직 한 번도 쓰이지 않음). 모집 중인 기업 1곳. 기업 계정 2개(모두 인증 완료 2502).

```
 비로그인             │ 기업                                       │ 개인
──────────────────────┼────────────────────────────────────────────┼──────────────────────────────────────
 /affiliation 목록·   │ ① 파트너 정보 (/mypage/affiliation-edit)   │
 상세(모달) 열람 가능 │   ├ 인증 전(2501): 모집·저장 비활성        │
 스크랩·신청 누르면   │   │   → 인증 모달에서 인증 → 2502          │
  → "로그인 후 이용"  │   └ 인증 후: 소개·태그·주소 입력,          │
                      │       [모집중] 체크 후 저장                │
                      │       └ 모집 Y인 기업만 목록에 노출 ──────▶│ ② /affiliation 검색·필터 → 상세 모달
                      │                                            │   ├ 스크랩(602) → 스크랩 목록
                      │                                            │   │   └ 그 기업이 공고를 올리면 알림
                      │                                            │   └ 소속 신청: 이력서(필수)+인사말
                      │ ③ 신청자 관리 ◀──────────알림+메일─────────│      → 501 대기 🔧 본인 이력서만
                      │   ├ 이름 클릭 → 열람 시각 기록             │      (수정 불가, 대기 중엔 취소 가능)
                      │   ├ 상세 → 이력서 보기 🔧                  │      (여러 기업에 동시 신청 가능)
                      │   ├ [합격] → 502 ───────알림+메일─────────▶│ ④ 소속 확정 (401 재직)
                      │   │   🔧 다른 기업 재직 중이면 400 + 안내  │   └ 내 소속 정보 화면
                      │   │      "현재 다른 기업에 재직 중"        │
                      │   └ [불합격] → 503 ─────알림+메일─────────▶│   불합격 확인
                      │ ⑤ 소속원 관리 (/mypage/affiliated-members) │
                      │   ├ 이력서 제목 클릭 → 이력서 🔧           │
                      │   ├ [퇴사 처리] → 402 ──────알림──────────▶│ 소속 해제
                      │   └ 공고에 소속원 대리지원 (대표 이력서)   │
                      │       🔧 이력서 변경 가능                  │   🔧 지원 내역에 '기업 지원 · 회사명'
                      │ 소속원 탈퇴 알림 ◀────────알림+메일────────│ ⑥ 직접 탈퇴 → 402
                      │                                            │    (회원 탈퇴 시에도 402)
──────────────────────┴────────────────────────────────────────────┴──────────────────────────────────────
 🔧 퇴사(어느 경로든)하면 그 기업이 낸 진행 중 대리지원은 자동 지원취소된다.
 🔧 기업 회원이 탈퇴하면 소속원 전원 퇴사(402)·대기 신청 불합격(503)·모집 중지 + 알림.
 소속은 한 사람당 한 기업만 가능하다(DB 제약).
 ⚠ 기업 계정은 소속 신청을 할 수 없다 — 화면에서만 막고 서버는 막지 않음.
```

## 4. 회원/계정 (v2)

운영 현황: 개인 101명, 기업 2명, 관리자 1명. 개인정보 동의는 일반 회원 103명 모두 'N'이다 — 🔧 지금은 가입할 때 'Y'로 저장(기존 회원 값은 그대로).

```
 비로그인 (입구)                         │ 개인(301)                                    │ 기업(302)
─────────────────────────────────────────┼──────────────────────────────────────────────┼──────────────────────────────────
 헤더 [로그인] / [회원가입] ────────────▶│ /login, /sign-up                             │
 헤더 [기업서비스 ▾]                     │                                              │
   ├ 기업 로그인 ────────────────────────┼─────────────────────────────────────────────▶│ /login?loginType=COMPANY
   │  (로그인 화면에서 누르면 redirect 유지)                                            │
   └ 기업 회원가입 ──────────────────────┼─────────────────────────────────────────────▶│ /sign-up?loginType=COMPANY
     🔧 설명 "기업 담당자 계정을 만듭니다"                                              │  (기업 로그인 화면의 가입 링크도 기업 가입)
 ① 회원가입                              │ 중복확인·이메일 인증(3분)                    │ 기업명·담당자·회사주소
   🔧 인증 남은 시간 표시                │ 이름·생년월일·성별·휴대폰·주소               │ 사업자번호는 받지 않음(의도)
   🔧 인증 5분이 지나면 재인증           │ 개인정보 동의 🔧 저장                        │  → 2501 미인증으로 시작
   🔧 서버 거절 사유는 그 칸에 표시      │  → 개인 로그인으로 이동 ✅                   │  🔧 → 기업 로그인으로 이동
 ② 로그인  access 30분·refresh 14일, 만료되면 자동 재발급 (소셜 로그인은 "준비 중")
   🔧 재발급 실패 → "세션 만료" 안내 + 회원 구분대로 로그인 화면 → 로그인 후 원래 화면
 ③ 계정 찾기 (개인·기업 공용 화면, 메일 인증번호 방식, 🔧 남은 시간 표시)
   ├ 아이디 찾기 → 결과에 회원 구분 표시 🔧 서버도 메일 인증을 확인
   └ 비밀번호 재설정 (5분 안에, 지나면 버튼 비활성 + 다시 찾기 링크)
   🔧 끝나면 회원 구분대로 로그인 화면
─────────────────────────────────────────┼──────────────────────────────────────────────┼──────────────────────────────────
                                         │ ④ 정보 수정 (비밀번호 재확인)                │ ④ 정보 수정 (🔧 '담당자 이름')
                                         │                                              │ ⑤ 기업 인증 → 국세청 진위확인 → 2502
                                         │ ⑥ 탈퇴 (소속 중이면 자동 402)                │ ⑥ 탈퇴 🔧 지원 취소·공고 삭제·
                                         │                                              │    소속원 퇴사·대기 신청 503·
                                         │                                              │    모집 중지 + 알림
                                         │  🔧 탈퇴하면 인증 쿠키도 지움                │
 재가입: 같은 아이디·닉네임은 불가, 같은 이메일·휴대폰은 가능 / 계정 관련 알림 없음
 ⚠ 탈퇴 안내문 「모든 정보는 삭제되며 복구 불가」는 실제(탈퇴 표시만, 개인정보·이력서는 남음)와 다름(기록만)
```

## 5. 연봉 (v1)

운영 현황: 실제 제출 1건(개인), 시드 4,000건.

```
 비로그인                     │ 개인(301)                                                           │ 기업(302)
──────────────────────────────┼─────────────────────────────────────────────────────────────────────┼──────────────────────────
 헤더 [연봉계산기] [연봉순위표] · 메인 배너                                                         │ 막는 곳 없음
 ① C 계산기 (/salary/calculator, 누구나 입력 가능)                                                  │ (개인과 똑같이 사용 가능)
   필수: 고용형태·직무·연차·지역·기술·연봉 / 선택 14종                                              │
   🔧 금액 칸은 10억(100,000만원) 상한                                                              │
   ├ 로그인 + 제출 이력 있음 → 모달 [이전 리포트 보기]/[새로 계산하기]                              │
   │   🔧 [새로 계산하기]는 이전 제출값으로 폼을 채움                                               │
   └ [분석] → 입력값을 이 탭의 sessionStorage에 저장                                                │
       🔧 비로그인이면 확인 모달 [아니오]/[기업 회원 로그인]/[개인 회원 로그인]
 ② D 분석 중 (/salary/analyzing)                                                                    │
   ├ 비로그인 → 로그인 → 분석 화면으로 복귀 → 자동 제출 ───────────────────────────────────────────▶│ 🔧 모달에서 기업 로그인 선택
   │  (주소 직접 진입이면 개인 로그인 화면 — 헤더 [기업 로그인]으로 바꿔도 복귀 유지)
   └ 로그인 → 제출(1인 1건, 다시 내면 갱신) + 3.2초 연출                                            │
       🔧 실패하면 입력값을 채운 채 계산기로                                                        │
 ③ E 리포트 (/salary/report, 서버에 저장된 내 제출 기준)
```
