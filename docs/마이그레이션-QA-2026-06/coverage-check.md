## 3. 미검증 + 스텁의심 우선순위 (액션성·중요도 기준)

### P0 — 미구현/누락 (신규 구현 트랙, '수정' 아님)
1. **소속 공개목록 `/affiliation`** (S1) — 페이지 자체 부재, 404. 헤더·robots 노출 중. → progress 8번과 동일 항목, **최우선**.
2. **프로젝트 지원/합격·불합격/인터뷰 확정** (S2) — 이미 check-project에서 확정된 P0 미구현 트랙.

### P1 — 액션 밀집 미검증 (실동작 핸들러 존재 → 내용검증 필요)
3. **마이/기업 소속 지원자 합격·불합격 처리** (`AffiliationApplicantsClient`) — `api.put .../apply` 상태전이(합격 502/불합격). 돈·채용 직결, 상태머신 검증 가치 최상.
4. **커뮤니티 게시판** (등록/수정/삭제/댓글/대댓글/추천/상태변경) — 쓰기 표면 가장 넓음. `data.status==='OK'` 패턴(로그인 검증서 가설 재확인 대상).
5. **커뮤니티 Q&A** (답변 등록/채택) — 채택은 상태전이 액션.
6. **마이/공통 정보수정** — 이메일 인증코드 발송/검증 + 프로필이미지 업데이트/삭제 + 회원정보 update. 인증·PII 흐름 포함.
7. **마이/개인 이력서 등록·수정 + 목록(삭제·대표지정·복사)** — 폼 필드 많음, 복사/대표 등 부가액션.
8. **마이/기업 소속 정보 편집** (`AffiliationEditClient`) — 모집해제/이미지 갱신·삭제/정보 update 멀티액션.
9. **마이/공통 프로젝트 등록·수정** (`ProjectPostClient`) — 폼 밀집 + S5 부분 미구현 동반.

### P2 — 단일 액션 미검증 (경량 처리, 핸들러 정상)
10. 회원탈퇴 / 소속탈퇴 / 구성원 퇴사처리 / 소속프로젝트 삭제 / 지원취소(2종) / 스크랩 삭제(3종).

### P3 — 부분 스텁(소기능) & 읽기전용
11. 게시판 신고기능 스텁 (S3), 소셜로그인 스텁 (S4), 지하철역 주소검색 미구현 (S5).
12. **일정 캘린더 읽기전용** (S6) — 쓰기 핸들러 부재. Vue 원본에 일정 등록/수정이 있었는지 대조 후 누락 여부 판정.
13. 메인 / 공지 목록·상세 — 조회만, 액션 없음. 최후순위.

## 4. 다음 검증 순서 제안
알람(진행 중) → P0 `/affiliation` 복원 → P1 순서대로(지원자 처리 → 게시판 → Q&A → 정보수정 → 이력서 → 소속편집 → 프로젝트등록) → P2 일괄 → P3 정리.
캘린더(S6)는 별도 'Vue 쓰기기능 존재 여부' 1줄 확인으로 누락/의도 분기.

### 결론
- **복원 필요 (마이그레이션 누락) 3건**: ① 게시판 신고, ③ 지하철역 주소검색, ④ 캘린더 일정 쓰기 — 모두 Vue에 동작 구현 존재.
- **복원 대상 아님 (원본부터 부재) 1건**: ② 소셜 로그인 — Vue 원본도 '준비 중' 스텁. Next는 스텁을 충실히 이관한 것이므로 누락 아님.
- 복원 난이도 메모: ③은 Kakao Maps JS SDK 로드/키 설정이 선행돼야 함(단순 폼 복원으로 안 됨). ①④는 백엔드 API가 Vue 시점에 이미 존재했으므로 프론트 모달·핸들러 복원 위주.
