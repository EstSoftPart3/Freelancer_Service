0est_server 와이파이 연결

운영 서버(192.168.2.104)는 est_server 와이파이 안에서만 SSH 로 접속된다. 이 와이파이에 붙으면 PC 가 192.168.2.x 주소(실측 때 192.168.2.105)를 받아 서버와 같은 망이 된다. 다른 와이파이·유선에서는 3·4단계가 Connection timed out 으로 실패한다.

est_server 는 숨김 와이파이다. 와이파이 목록에 나타나지 않으므로 처음 한 번은 직접 등록해야 한다. 비슷한 이름(est_5G · est_2.4G 등)은 다른 망이다. 비밀번호는 docs/시크릿.md 의 「est_server 와이파이」 항목(없으면 담당자에게).

0-1. 등록 방법 ① — Windows 설정 화면

  1. Win + I → 네트워크 및 인터넷 → Wi-Fi → 알려진 네트워크 관리
  2. 네트워크 추가(Windows 10 은 「새 네트워크 추가」)
  3. 입력:
    칸값
    네트워크 이름est_server (밑줄 포함, 대소문자 그대로)
    보안 유형WPA2-개인 AES (공유기가 WPA2/WPA3 겸용이라 WPA3-개인 도 된다)
    보안 키시크릿.md 의 비밀번호
    ☑ 자동으로 연결체크
    ☑ 네트워크가 브로드캐스팅하지 않는 경우에도 연결반드시 체크 — 숨김 와이파이라 이게 없으면 못 붙는다
  4. 저장 → 잠시 뒤 자동 연결된다. 안 되면 작업 표시줄 와이파이 목록 맨 아래 「숨겨진 네트워크」에서 연결

이 화면 절차는 캡처 없이 글로만 적었다.
