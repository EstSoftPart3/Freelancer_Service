## 2. 새 노트북 세팅

1. **기본 도구 설치·저장소 받기** — `docs/도구/개발환경-세팅-가이드.pdf` 순서대로 한다.
   (Git, JDK, Node, Python, Chrome, 사무실 와이파이, `git clone` → **반드시 `C:\dev\Freelancer_Service`**)
2. **1번에서 옮긴 파일을 같은 위치에 복원한다.**
   - Windows 사용자 이름이 `ESTSOFT` 가 아니면 `C:\Users\<새이름>\` 아래로 옮긴다.
   - 🔴 이 경우 `.oci\config` 의 `key_file=` 경로를 새 사용자 폴더로 고친다.
3. **환경변수** — PowerShell 에서 (값은 `시크릿.md`):
   ```powershell
   [Environment]::SetEnvironmentVariable('FREELANCER_DB_PW', '<시크릿.md 의 값>', 'User')
   ```
4. **Python 패키지**
   ```powershell
   pip install pymysql oci playwright pymupdf pillow
   ```
   (Playwright 는 설치된 Chrome 을 `channel='chrome'` 으로 쓰므로 `playwright install` 은 필요 없다)
5. **Claude Code 설치·로그인** — npm 전역 설치(`npm i -g`) 말고 **네이티브 설치**로 한다
   (npm 설치는 세션 중 자동 업데이트하다 `claude` 명령이 사라지는 문제가 있었다). 설치 후 `claude doctor` 로 확인.
   그다음 `C:\dev\Freelancer_Service` 에서 `claude` 실행.
   첫 질문으로 "메모리 읽히는지" 확인 — 예: "회의 피드백 5건 진행 상황 알려줘"
6. **동작 확인**
   - DB 스크립트(읽기 전용): `python docs/도구/db-diff-schema.py --sql` → "구조 차이 없음" 이 나오면 DB 비번·접속 OK
   - 실서버 SSH(사내망): `ssh -i ~/.ssh/id_ed25519_casaos estsoft@192.168.2.104 "docker ps"`
   - 로컬 기동: 백엔드 `./gradlew bootRun`, FO `npm run dev:clean`

1. `C:\dev\oci-retry\` 를 복원하고, `.oci\` 와 `.ssh\id_ed25519_dbportal*` 이 있는지 확인한다.

   - Git Bash: `... | tee -a oci-retry.log`
